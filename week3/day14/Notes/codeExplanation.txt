RAG CODE — COMPLETE SIMPLE EXPLANATION

PURPOSE:
Ye code ek simple RAG system bana raha hai.

RAG ka flow:
Knowledge → Embedding → Qdrant → Search → Context → LLM → Answer


1. IMPORTS + API KEYS
---------------------

13. NORMAL SEARCH FUNCTION
--------------------------

def search(query, top_k=3):

    query_vector = model.encode(query).tolist()

    results = client.query_points(
        collection_name=COLLECTION_NAME,
        query=query_vector,
        limit=top_k,
        with_payload=True,
    ).points

    return results


Suppose user asks:

"How many vacation days do I get?"


STEP 1:

query = "How many vacation days do I get?"


STEP 2:

query_vector = model.encode(query).tolist()

Question ko embedding mein convert kiya:

Question
   ↓
Embedding Model
   ↓
384 numbers


STEP 3:

Qdrant ko question vector diya.

Qdrant check karega:

"Kaunse stored vectors is question ke sabse similar hain?"


STEP 4:

limit=3

Top 3 similar documents lao.


STEP 5:

with_payload=True

Result ke saath original document information bhi lao.


So normal search:

QUESTION
   ↓
EMBEDDING
   ↓
VECTOR
   ↓
QDRANT
   ↓
SIMILAR DOCUMENTS
   ↓
TOP 3 RESULTS


14. FILTER SEARCH
-----------------

def search_with_filter(query, query_filter=None, top_k=3):

    query_vector = model.encode(query).tolist()

    results = client.query_points(
        collection_name=COLLECTION_NAME,
        query=query_vector,
        limit=top_k,
        with_payload=True,
        query_filter=query_filter,
    ).points

    return results


Ye normal search jaisa hi hai.

ONLY EXTRA THING:

query_filter


Matlab:

"Search karte waqt ek condition bhi follow karo."


15. FILTER BANANA
-----------------

reimbursement_filter = Filter(
    must=[
        FieldCondition(
            key="category",
            match=MatchValue(value="reimbursement")
        )
    ]
)

Iska simple meaning:

category MUST BE reimbursement


Example:

Document 1:
category = vacation
❌

Document 2:
category = reimbursement
✅

Document 3:
category = salary
❌

Document 4:
category = reimbursement
✅


Filter ke baad sirf reimbursement wale documents consider honge.


16. FILTER SEARCH CALL

results = search_with_filter(

19. LLM FUNCTION
----------------

def ask_llm(question, context):

    prompt = f"""
    Answer the question using only the information provided below.

    Context:
    {context}

    Question:
    {question}

    If the answer is not present in the context, say:
    "I don't know based on the provided information."
    """

LLM ko do cheezein de rahe hain:

1. Question
2. Context


Example:

Question:
How many vacation days do I get?

Context:
You get 20 vacation days.


LLM ko instruction:

"Sirf diye gaye context se answer dena.
Apni taraf se information mat banana."

response = groq_client.chat.completions.create(

)

24. SABSE IMPORTANT CONCEPTS
----------------------------

Embedding:
TEXT → NUMBERS

Vector:
384 numbers representing the meaning of text.

Qdrant:
Vectors ko store aur search karta hai.

Payload:
Original information/metadata.

Similarity Search:
Question ke meaning ke closest documents dhoondna.

Filter:
Extra condition lagana.

Example:

category = "reimbursement"

Context:
Qdrant se mile relevant documents ka text.

LLM:
Context ko use karke final human-readable answer banata hai.

RAG:
RETRIEVE → AUGMENT → GENERATE
